# Frontend

React and Vite client for the Iqbal Movers transport-management system. It uses the Node.js API at `http://localhost:4000/api/v1` by default.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Set `VITE_API_URL` when the API is hosted at a different address. For database setup and backend commands, see [backend/DATABASE_SETUP.md](../backend/DATABASE_SETUP.md).
